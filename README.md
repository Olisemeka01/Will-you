# 💜 Will You Be My Girlfriend?

An interactive Valentine's Day proposal website with a playful romantic design.

## Features

- **Playful "No" Button** - Runs away and shrinks when clicked!
- **Confetti Celebration** - Beautiful confetti burst when she says "Yes"
- **Floating Hearts** - Animated heart particles in the background
- **Romantic Design** - Envelope-style striped borders and scalloped edges
- **Accessibility** - Keyboard navigation, focus states, reduced motion support

## How to Use

Simply open `code.html` in any web browser. No build process or dependencies required!

## Customization

Edit the following in `code.html`:
- **Message**: Modify the romantic text in the `<p>` tag
- **Name**: Change "Will You Be My Girlfriend?" to your custom message
- **Colors**: Adjust the Tailwind config color values
- **"No" Button Labels**: Edit the `noLabels` array in the script section

## Technologies

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- canvas-confetti (celebration effects)
- Google Fonts (Great Vibes, Bricolage Grotesque, Plus Jakarta Sans)
